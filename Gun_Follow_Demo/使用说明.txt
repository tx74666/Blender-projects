举枪跟随功能原型 — 使用说明

样例使用已保存的真实 Cosha 角色副本，不包含当前 Main 中尚未保存的编辑。请在独立 Blender 窗口打开，保留现有工作窗口及未保存内容。

打开前，需启用兼容的 Character Designer 插件；打开时，允许这份样例内可信的注册 Text 执行（Auto Run），以恢复双手跟随。

1. 切到 Object Mode，选中 Gun_CTL。
2. 用 G 移动、R 旋转 Gun_CTL。双手通过现有 IK 跟随枪上的握点；移动幅度以双臂可达范围为限。
3. 动画范围为第 1–96 帧，24 fps。切到要修改的帧，调整 Gun_CTL，再用 I 为 Location／Rotation（位置／旋转）插入关键帧。样例动画只在 Gun_CTL 上打键，双手由跟随关系驱动。
4. 在 Gun_CTL 的自定义属性中关闭 Follow Hands，可暂停跟随；重新开启后再轻移一下枪即可触发重新对齐。纯 Python 改这个属性时，需要显式发送对象更新通知；实际面板开关的单独点击尚未验证。
5. 播放时间轴查看动作，也可以逐帧调整枪的位置和朝向。

枪是占位模型，手指握姿仅作粗调示意，尚非最终枪模型或最终握姿。

Blender 可以用约束和 IK 实时调整这类跟随关系。导入 Unity 时，需要把最终骨骼动作烘焙为动画，或在 Unity 中重建相应的 IK 跟随关系。

台球的动态目标、身体多种可行姿态的选择等内容留待后续在 Unity 中处理，本样例尚未实现。
