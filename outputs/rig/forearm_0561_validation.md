# Character Designer 0.56.1：小臂校准与手腕检查

日期：2026-09-13。源码在 `D:/MyRepository/Blender-addons-by-Randy`；已打包、部署并刷新本机 Blender，X 校验副本与源码均无差异。未提交或推送 GitHub。

## 修改结果

- 保留已有手腕旋转机制。当前 X 的左右 `CTRL_hand_IK` 均关闭了使用显示变换轴的标志；恢复这两个标志后，局部 Y 会跟随当前手腕。没有重建骨骼、修改骨骼静止位置或权重。
- 捕获真实闭合环线，支持选中种子沿四边面邻接扩展、手动补环、调整起点/终点和当前圈。保存顶点对应关系和静止位置次序，换姿势不重新识别。分叉、开口及失效拓扑明确拒绝。
- 支持单圈、N 个不同圈（包含当前圈）、间隔及独立平滑操作。额外校正仅在边界内生效，边界过渡也在范围内完成；原有蒙皮仍正常工作。未加入可选的权重 Clamp。
- 两条边界浅蓝，当前圈亮黄；重合时蓝色宽线与黄色细线同时可见。绘制实际变形后的控制笼环线，不用估算圆代替。
- 新捕获默认采用轻度空间缓入缓出，强度 0.4：`s=(1-k)t+k(3t²-2t³)`。t 使用真实静止位置。保持已确定的边界比例、实际手腕角度和正负号；不设置 30°～45°硬限制。
- 旧记录和手调结果不会因打开面板或换姿势而重新生成。需要替换时主动使用 **Apply Default Distribution**。Confirm 保存，Cancel/Esc 恢复本次编辑前状态，Undo/Redo 只记录有效修改。
- 双侧操作先检查两侧。修复相同 RNA 数值产生空撤销步骤、双侧移除遇到另一侧 Shape Key 名称冲突可能只移除一边的问题。

## 使用

选手腕控制器或对应身体网格 → **Forearm Twist → Edit Calibration**。已有校准直接继续编辑；没有有效捕获时使用 **Capture / Repair Loops**。

Current 可用上一圈/下一圈或 **Pick** 在视图中选圈。**Set Start / Set End** 将当前圈设为边界。当前比例与实际测试角度下的目标角度显示在一起。

展开 **Batch / Distribution** 可移动边界、设置圈数和间隔、生成默认分布或显式平滑。所有预览都可取消；确认后保存 blend，再打开仍可编辑。

## 当前场景与限制

现场预览全部取消，保留原有手调校准。X.blend 已保存手腕轴修正；事前完整备份为 `X_before_forearm_0560_20260913_053846.blend`。保存后独立读取两份文件比较通过：仅两个预期手腕轴标志改变，姿势、原始骨架、拓扑、权重、所有 Shape Keys、校准原始记录、约束、修改器与动画完全一致，数值差为 0。

160 组合采用 Blender 变换算子执行与 Global 下第二次 Y 相同的 Local Y 操作，**不是逐一发送物理 R/Y/Y 键**。已验证实际皮肤控制笼计算和现场局部预览，但没有逐姿势人工评审所有最终细分表面的体积与美观，也没有覆盖任意拓扑、任意骨架及任意修改器组合。现有原型限制继续保留：线性 Armature 蒙皮、相对 Shape Keys、±120°局部校正以及运行时需启用插件。
