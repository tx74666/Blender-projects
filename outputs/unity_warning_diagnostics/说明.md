# Unity 导出警告操作，0.58.1

Blender 插件及 X 验证副本已经部署 0.58.1，部署核对一致。运行中的 Blender 需点击 Refresh。

缺权重警告下新增 Locate Unweighted Vertices，重新检查当前原始网格，进入编辑模式选择、显示并聚焦缺权重点。它不按上次导出的 FBX 编号选点，也不自动改权重。如果当前原网格已经修好，会提示重新导出；只有修改器生成的缺权重点不会被随意映射到近邻原始顶点。

实际 Cosha 原始顶点 3574、3575 确实没有权重。两者均位于嘴部，各连接三条边和三个面，参与 Mouth_Happy。周围顶点的 Head 权重为 1.0；它们不是应当直接清除的游离点。定位后可选择 Head 顶点组，以 1.0 Assign 补权重。本次未自动修改。

材质警告下新增 Use Simple BSDF for Export，只对下一次导出的副本采用简单 Principled BSDF。Use Original on Next Export 可撤回该选择；源材质节点一直保留。选择支持保存重开与 Undo/Redo。

Stocking Main 当前是 Principled + Magic Texture／Math／Color Ramp 程序颜色。简化保留深灰底色约 0.01877598、粗糙度 0.5、金属度 0、不透明度 1，暂时省略程序织纹。直接受支持的底色贴图可保留；复杂效果会在报告的 simple_materials 字段明确列出。Unity 接收标准材质参数，继续使用其自身着色器；已有手工 Unity 材质映射不会被强行覆盖。
