# 裙子检查场景 · Character Designer 0.40.0

打开 [X_Skirt_Setup_0.40.0.blend](X_Skirt_Setup_0.40.0.blend)。这是从已保存的 X 创建的独立副本，原来的 X.blend 和两个正在编辑的 Blender 窗口未被改动。

进入右侧 **Character Designer → Clothing**。裙子 `Dress` 已设置完成，包含 8 个方向、每方向 4 节裙骨；大型腰圈／中段圈／裙摆圈负责整体塑形，在 Pose Mode 中用 G、R、S 操控。小菱形是线框上的位置控制点，用 G 移动；原地旋转或缩放单个小菱形不会改变它所绑定的点。原始裙子网格保留，线框是根据它拟合的光滑椭圆截锥。

- 时间轴 **1–61 帧**有一段轻微摆动示范，并已逐帧烘焙。它用于检查控制与连续性，不是角色行走成品动画。
- **Physics** 滑块调整物理摆动叠加量；设为 0 可单独检查手动控制。
- **Colliders / Select Colliders** 显示和选择骨盆、左大腿、右大腿的封闭凸碰撞代理。需要你最后目测贴合度，尤其是抬腿、坐下时；可用 G / S 调整。
- 调整动画、控制器或 Collider 后，使用 **Clear → Bake Physics**，覆盖所需的完整帧范围。烘焙时按 Esc 可取消。
- **Inspect Baked Animation** 查看独立烘焙副本，**Return to Controls** 回到可编辑设置。副本按帧保存骨骼与角色整体运动，不需要物理缓存或插件运行。
- 烘焙副本初始关闭渲染可见性，以免与原裙重叠。要正式渲染副本，开启 `Baked Skirt · Dress` 集合的渲染，并关闭原裙的渲染。

首次套用到其他裙子时，选中未绑定的完整环带裙面，点击 **Create Skirt Setup**。当前版本要求上下各一个闭合开口、规则四边环带；不直接处理开衩、多层断片或已绑定的裙子。场景有多个角色骨架时，在 Attachment 中指定骨架和 Hips／骨盆。

本轮验证：真实 X 的 61 帧实时与烘焙副本随机跳帧对比，最大世界坐标误差约 0.0000123；保存重开、禁用插件后仍匹配。独立测试还删除了原角色与控制系统，验证副本能独立播放。物理层沿骨链连续传递，测试骨头连接间隙为 0。布料碰撞代理和控制网格是近似，复杂姿势仍须检查穿插；该控制网格未开启自碰撞。
