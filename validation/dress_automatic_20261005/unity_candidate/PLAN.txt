Minimum dynamic addition (only dressCurrent)

The original nine leg/squat/lunge cases and all original menu routes remain.
Three more cases are appended, bringing this route to twelve cases:

- walk_native_two_cycles resolves one exact base slot named Walk_N through the
  current saved controller/override hierarchy. It rejects cycles/null controllers,
  ambiguous slots/paths, unsaved asset identities, object curves and unknown or
  non-Humanoid body curves. The effective saved clip must already be a looping
  native Humanoid clip of 0.1-5 seconds. No fallback, clip authoring, loop-setting
  change or retiming is performed. Each of the first two full-weight periods needs
  native clip/body samples, actual changes on both thigh bones, and at least ten
  real positive-substep Magica frames. Missing bindings reject before fixture work.
- root_yaw_turn applies a continuous 90-degree root yaw, hold and return. The
  physics-off reference receives the identical input; captured view axes turn with
  the character. Root input is applied after body blending, before native transform
  reads. The source clip's automatic root motion/events are disabled on clones only.
- root_abrupt_stop moves the root with a commanded 0.5 m/s trajectory, changes
  velocity to zero while keeping position continuous, holds, and then returns.
  Actual Time.deltaTime-derived velocity and capped QA-clock velocity are recorded
  separately. Real approach speed must reach 0.45 m/s and at least ten observed
  stationary frames must follow. An extra stop-phase native image captures response.

Root/native center input is compared read-only to the actual native historical
component frame and runtime teleport parameters using |scale|/|initScale|. Anchored,
synchronized, external or negative-scale frames refuse; a stimulus reaching the
saved auto-teleport threshold refuses rather than changing a setting or accepting
a silent reset. Build/reset warmup is excluded from this effect check.

Each current-Dress case records moving-particle response in a Waist rigid frame:
translation and rotation are removed, while distances retain world metres (no
scale division). Finite/root/frame checks are separate from settling. At least
five real tail frames and thirty native positive-substep frames are required.
The existing 0.35 m/s QA tail threshold is exposed as diagnostic attachmentSettled;
above-threshold cases do not receive numerical completion. It is not an art/game
quality or triangle-safety threshold.

Contact evidence is paired Pre/Post collisionNormalArray data on moving particles.
Edge mode can retain an old normal after contact ends. Retained nonzero normals are
counted separately; only a nonzero direction change in a frame with native substeps
is a sufficient fresh collider-normal witness. This undercounts same-direction
persistent contact and describes native friction/proximity in the last solver
substep, not the interpolated displayed particle pose or mesh intersection.
At least one fresh witness is required for this batch's contact coverage to be
marked observed. No native arrays are cleared and no solver/parameters are modified.
