Decision
Use the existing artist Scene and CoshaRig as the editing target. A verified animation
package can be converted into Actions for that rig: another mesh, permanent skeleton,
or animation Scene is not intrinsically required. Keep the original mesh, Rest data,
weights, Shape Keys, materials, control objects, Bone Collections and colors.
Do not attach the imported .001 Action directly; its channels use the imported Rest basis.

Implementation scope selected

   assets are not evidence of the package's historical source version.

Editing boundary
Existing code supplies exact FK animation on supported original control graphs.
Limb IK/FK matching can key pose-preserving switches, but animated spine switching
is explicitly guarded out. Full-clip IK conversion and unrestricted spine animation
switching must not be advertised as already supported.
